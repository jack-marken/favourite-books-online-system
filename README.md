## Instructions
1. Install the latest version of python, Python 3.14.5
2. Run the command `python -m venv .venv` to create a virtual environment
3. Activate the environment by running `source .venv/bin/activate` on Mac or Linux, or run `./.venv/Scripts/Activate.ps1` on Windows Powershell
4. Install Flask with `pip install flask`
5. Run the server with python main.py
